A tiny stack virtual machine in TypeScript for [tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): it runs all 40 instances of make.fun's tiny stack ISA (32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and the ten traps) and writes each answer's stdout bytes and exit code.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
